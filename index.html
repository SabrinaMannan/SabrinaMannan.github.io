BIA phase angle statistical analysis

A reproducible Python pipeline for bioelectrical impedance analysis

  • Translated an existing R analysis into a fully reproducible Python workflow, from preprocessing to publication-quality figures.
  • Compared body composition and phase angle across four study groups: EGD healthy, EGD low BMI, pregnant healthy, and pregnant low BMI.
  • Applied normality tests, one-way ANOVA with Tukey HSD, Kruskal–Wallis, Spearman correlation, and linear regression with diagnostics (VIF, residual plots).
  • The dataset is confidential, so the repository shares only the code and generated outputs.
  • Biostatistics
  • Regression
